# Evidence Schema (v3)

## Execution Manifest (execution-manifest.json)
Generated by start-execution.ts at the beginning of a run.
- \executionId\: RUN-<UTC>-<RANDOM>
- \epicId\: Target Epic
- \createdAtUtc\: Timestamp
- \createdByTool\: Tool string
- \epositoryCommitSha\: Git commit hash
- \gitWorkingTreeClean\: Boolean
- \
odeVersion\, \
pmVersion\, \platform\: Environment info
- \status\: RUNNING | COMPLETED | FAILED

## Stage Evidence (evidence.json)
Generated by ecord-evidence.ps1 for each stage.
- \executionId\: Reference to manifest
- \epic\, \stage\, \commandId\: Stage identifiers
- \exitCode\: Exit status
- \startedAtUtc\, \inishedAtUtc\, \durationMs\: Timing
- \esolvedCommand\, \cwd\: Command execution details
- \epositoryCommitSha\: Git commit at stage execution time
- \stdoutSha256\, \stderrSha256\: Hashes of log files
